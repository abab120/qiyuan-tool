🧰 栾悄工具箱

一个简洁、实用的 Windows 多功能工具箱

集成 AI 助手、自动化、进程管理、文件处理、局域网传输等常用功能。

📖 项目简介

栾悄工具箱 是一个面向 Windows 的桌面效率工具合集。

项目希望把日常使用的各种小工具集中到一个程序中， 减少安装多个软件以及频繁切换程序的麻烦。

✨ 主要功能

🤖 AI 助手

支持自定义 API、模型、Temperature 和 AI 人格。

🖱️ 自动点击

提供鼠标自动连续点击功能。

🎯 点小球

简单的鼠标操作与反应小游戏。

⚡ 反应力测试

测试鼠标点击反应速度。

🧩 进程管理

查看和管理 Windows 运行进程。

📦 压缩包工具

提供常见文件压缩与解压功能。

🌐 局域网传输

在局域网设备之间快速传输文件。

🛠️ EXE 打包

辅助将 Python 项目打包为 EXE。

📚 常用库管理

快速安装和管理常用 Python 库。

🖼️ 软件截图

🤖 AI 助手

AI 助手支持自行配置：

  • API 接口地址
  • API Key
  • 模型名称
  • Temperature
  • System Prompt / AI 人格

支持兼容 OpenAI API 格式的接口。

⚠️ API Key 属于敏感信息，请勿将自己的 API Key 上传到 GitHub。

🚀 使用方法

直接下载

进入仓库的 Releases 页面，下载最新 Windows 版本。

源码运行

git clone https://github.com/abab120/qiyun-tool.git
cd qiyun-tool
