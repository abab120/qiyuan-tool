📖 项目介绍

一个程序，解决更多日常需求

柒悁工具箱 是一个面向 Windows 的桌面效率工具合集。 将日常使用中的各种小工具集中到一个程序中， 减少安装大量独立软件以及频繁切换程序的麻烦。 目前包含 AI、自动化、测试、进程管理、 文件处理、局域网传输以及开发辅助等功能。

✨ 主要功能

常用功能集中在一个工具箱

🤖 AI 助手

支持自定义 API 地址、API Key、 模型名称、Temperature 以及 AI 人格。

🖱️ 自动点击

提供鼠标自动连续点击功能， 适合各种需要重复点击的场景。

🎯 点小球

简单的鼠标操作小游戏， 测试点击速度与准确度。

⚡ 反应力测试

测试你的点击反应时间， 看看你的反应到底有多快。

🧩 进程管理

查看和管理 Windows 当前正在运行的程序与进程。

📦 压缩包工具

提供常见文件压缩、 解压以及相关辅助功能。

🌐 局域网传输

在同一个局域网的设备之间 快速进行文件传输。

🛠️ EXE 打包

提供 Python 项目 EXE 打包辅助功能。

📚 常用库管理

快速查看、安装和管理 常用 Python 第三方库。
